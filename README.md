# Python Technologies Statistics

Скрапер вакансій [jobs.dou.ua](https://jobs.dou.ua/) (категорія Python) та аналіз того,
які технології найчастіше згадуються в описах, з розбивкою за рівнем досвіду.

## Як працює

1. `scraper/scrape.py` збирає посилання на вакансії для кожного рівня досвіду
   (`0-1`, `1-3`, `3-5`, `5plus`). Спочатку через RSS, а якщо він порожній — через
   `xhr-load` («Більше вакансій»). Потім завантажує сторінки вакансій і зберігає
   `data/raw/vacancies_YYYY-MM-DD.jsonl`.
2. `analysis/analyze.py` шукає технології за регулярками з `config.py` і будує графіки
   у `charts/`, а також веде `data/history.csv` для трендів.

Вакансія може бути одразу в кількох рівнях досвіду (наприклад, Junior/Middle):
в графіках по рівнях вона враховується в кожному, в загальному — один раз.

## Запуск

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
python -m scraper.scrape
python -m analysis.analyze
```

Перед запуском вкажіть свій контакт у `USER_AGENT` в `config.py`.

## Результати

- `charts/overall_<дата>.png` — топ технологій
- `charts/by_experience_<дата>.png` — за рівнем досвіду
- `charts/trends.png` — динаміка (з'являється після 2+ запусків у різні дати)

## Обмеження

- Підрахунок за ключовими словами: збіг у тексті не означає обов'язкову вимогу.
- Склад технологій і регулярок редагується в `config.py`.
- Скрапер працює без авторизації, з паузами між запитами. Дотримуйтесь правил сайту.
